# TindaCloud API Endpoints

This is a full documentation of the API endpoints used by the TindaCloud application.

The API is designed using RESTful principles and serves multiple client applications, including the Marketplace, Merchant Dashboard, and Mobile Application.

## API Information

| Property | Value |
| --- | --- |
| API Style | REST |
| Version | v1 |
| Base URL | `/v1` |
| Data Format | JSON |
| Authentication | JWT Bearer Token |
| Authorization | Role-Based Access Control (RBAC) |
